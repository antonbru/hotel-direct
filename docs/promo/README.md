# Промо-ролик «Отель напрямую»

Ролик собран кодом: HTML-сцена рисуется покадрово, кадры кодируются в mp4.
Живой записи экрана нет — страница агрегатора и карточка нарисованы схематично,
чтобы зритель читал не чужой сайт, а карточку расширения.

## Что в папке

- `index.html` — вся сцена: левая плашка, окно браузера, макеты страниц, карточка, финальный экран.
- `assets/` — шрифт Tilda Sans (заголовки) и иконка расширения.
- `hotel-direct-promo.mp4` — готовый ролик 1920×1080, 30 fps, 30 с, без звука.
- `poster.jpg` — кадр-обложка.

## Как пересобрать

```bash
npm install                 # нужен playwright-core (двигает Chrome)
npm run promo               # 900 PNG-кадров -> /tmp/promo-frames (~2 мин)
```

Кодирование:

```bash
ffmpeg -y -framerate 30 -i /tmp/promo-frames/f_%04d.png \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -movflags +faststart \
  docs/promo/hotel-direct-promo.mp4
```

Проверять отдельные куски (быстро, 1–2 секунды):

```bash
node scripts/render-promo.mjs --frames /tmp/x --from 9 --to 11
```

Размер кадра и длительность задаются флагами: `--w 1080 --h 1920 --dur 15`
(для вертикальной версии сцену придётся перекомпоновать, а не только поменять размер).

## Таймлайн

| Время | Левая плашка | Правая часть |
|---|---|---|
| 0.0–4.4 | «Отель нашли. А официальный сайт — где?» | карточка отеля на Островке, курсор листает |
| 4.4–9.0 | **1** Откройте карточку отеля на агрегаторе | подсветка строки «№ … в реестре Росаккредитации» |
| 9.0–14.2 | **2** Расширение находит отель в реестре | карточка выезжает снизу: сайт, телефон |
| 14.2–18.8 | Сайт и телефон — в одной карточке | страница притухает, карточка крупным планом |
| 18.8–23.6 | **3** Нажмите «Открыть сайт отеля» | курсор жмёт кнопку → переход на сайт отеля |
| 23.6–27.0 | Работает на Островке и 101hotels | 101hotels, вариант «только телефон» |
| 27.0–30.0 | — | финальный экран с логотипом и кнопкой |

## Как править

- Тексты — блоки `.copy` в `index.html`.
- Тайминги — массив `SC` в конце `index.html` (границы сцен в секундах).
- Цвета — `#0A3A36` (фон), `#5EEAD4` (акцент шагов), `#0F766E` (кнопки карточки).
- Внутри `setTime(t)` всё считается от времени `t`: CSS-анимаций нет намеренно —
  иначе кадры при покадровом рендере получаются недетерминированными.
