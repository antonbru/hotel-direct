# Политика конфиденциальности расширения «Прямые брони»

Последнее обновление: 27 ноября 2026.

> **English summary.** Direct Bookings collects no personal data, browsing history or
> cookies. It keeps settings, a hidden-hotel list and a 30-day registry cache
> locally in the browser. The only network request goes to the public registry at
> `tourism.fsa.gov.ru` and carries only the hotel ID taken from the page the user
> opened. No data is sent to third parties, and the extension earns no commission.

## Какие данные обрабатываются

Расширение **не собирает** персональные данные, историю просмотров, cookies и не ведёт
аналитику. Учётных записей нет.

Локально, в хранилище браузера (`chrome.storage.local`), лежит только:

- список отелей, для которых пользователь скрыл карточку;
- флаг «показывать карточку» из настроек;
- кэш ответов реестра (название, сайт, телефон отеля) на 30 дней, чтобы не запрашивать
  один и тот же отель повторно.

Эти данные не покидают устройство и удаляются вместе с расширением.

## Сетевые запросы

Единственный внешний адрес — `https://tourism.fsa.gov.ru` (Единый реестр объектов
классификации, Росаккредитация). Запрос содержит только идентификатор объекта
размещения, взятый со страницы агрегатора, которую пользователь уже открыл.
Никакие данные о пользователе не передаются.

## Третьи лица

Расширение не использует партнёрские ссылки, рекламные идентификаторы, внешние
скрипты и SDK аналитики. Комиссию с бронирований расширение не получает.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `storage` | Настройки, скрытые отели, кэш ответов реестра |
| `https://tourism.fsa.gov.ru/*` | Запрос карточки отеля в реестре |
| Content scripts на `ostrovok.ru`, `101hotels.com` | Прочитать ссылку на реестр на открытой пользователем странице |
